# Admin Frontend Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the new `frontend/` app (TanStack Start SPA, Tailwind v4, shadcn, oxlint/oxfmt, working light/dark/system theme), build it into the Go binary, and serve one placeholder page from Go at `/admin/next` behind the existing auth.

**Architecture:** `frontend/` builds a static SPA (`dist/client/_shell.html` + hashed assets, base `/admin/app/`). Go maps `frontend/dist/client` to `/admin/app` in stuffbin, serves assets there without auth, and serves the shell at `/admin/next` through the existing authenticated route group. Go rewrites the shell at serve time so deployments under a root-URL sub-path work. Old Go-template admin is untouched.

**Tech Stack:** Bun, Vite, TanStack Start (SPA mode) + TanStack Router, React, Tailwind CSS v4 (`@tailwindcss/vite`), shadcn/ui (Radix), oxlint, oxfmt, `bun test`, Go (echo, stuffbin), Playwright.

**Spec:** `docs/superpowers/specs/2026-10-15-frontend-migration-design.md`. This plan covers the first slice of its rollout step 1 and the shell hand-off. Later plans (separate documents): bootstrap API + layout + data table, then one plan per page group.

## Global Constraints

- Dark mode is class-based: `.dark` on `<html>`; modes light / dark / system; applied before first paint.
- localStorage key `theme` (same key as the old admin): value `light` or `dark`; absent = system.
- TanStack Start runs in SPA mode; no Bun/Node process at runtime; single Go binary.
- Build output served at URL prefix `/admin/app/` (built with Vite `base: '/admin/app/'`). Old admin keeps `/admin/static/`.
- Tooling: bun for install/scripts/tests, oxlint for lint, oxfmt for format. No eslint, no prettier.
- Public pages and login/OIDC/password-reset stay Go-rendered.
- Commits: plain messages, **no Claude/Sonnet/Co-Authored-By trailer**. Work on branch `feat/frontend-tanstack-start`.
- Go is not installed on the host: run all Go commands (`make`, `go test`) inside the dev container (`make run-dev-docker`, then run in that shell, repo at `/app`).

## Review Focus

Failure modes the spec implies but no feature test would hit by default. Each has a test or check in the task named.

1. Root URL with a path (`app.root_url = https://host/lm`): shell asset URLs and runtime chunk URLs must carry `/lm`. Task 4 (`TestRewriteShell*`), Task 6 (manual curl).
2. Hostile or malformed root path (contains `<`, quotes, spaces) must not inject markup into the shell. Task 4 (`TestRewriteShellRejectsUnsafeRootPath`).
3. `localStorage` throws (private mode / blocked) or holds junk (`"purple"`): theme falls back to system, no crash. Task 2 (`theme.test.ts`).
4. User on "system" whose OS theme flips while the page is open: UI follows live. Task 2 (`theme.test.ts` covers `applyTheme`; provider listener checked manually in Task 2 Step 14).
5. Frontend not built (no `frontend/dist/client`): Go must still start and `/admin/next` must 404 cleanly, not crash. Task 4 (guarded mapping), Task 6 (manual check).
6. Unauthenticated request to `/admin/next` must redirect to login with `next`, never serve the shell. Task 6 (`frontend-foundation.spec.js`).

```ts
const GO_URL = process.env.LISTMONK_URL ?? 'http://localhost:9000';

// URL prefix the built assets are served under by Go (see cmd/init.go).
const APP_BASE = '/admin/app/';

const PROXIED = [
  '/api',
  '/admin/login',
  '/admin/static',
  '/admin/custom.css',
  '/admin/custom.js',
  '/public',
  '/uploads',
];

export default defineConfig(({ command }) => ({
  base: command === 'build' ? APP_BASE : '/',
  resolve: { alias: { '@': path.resolve(import.meta.dirname, 'src') } },
  server: {
    port: 5173,
    proxy: Object.fromEntries(PROXIED.map((p) => [p, { target: GO_URL }])),
  },
  experimental: {
    // Chunk and preload URLs resolved from JS honor a root-URL sub-path. Go sets
    // window._LM_ROOT when it serves the shell (internal/adminapp/shell.go).
    renderBuiltUrl(filename, { hostType, ssr }) {

      }
      return undefined;
    },
```

- [ ] **Step 3: Implement `frontend/src/lib/theme.ts`**

```ts
export type Theme = 'light' | 'dark' | 'system';

export const THEME_KEY = 'theme';

export interface ThemeRoot {
  classList: { toggle(token: string, force?: boolean): boolean };
  style: { colorScheme: string };
}

// Same storage contract as the old admin: "light" | "dark", key absent = system.
export function readStoredTheme(storage: Pick<Storage, 'getItem'>): Theme {
  try {
    const v = storage.getItem(THEME_KEY);
    return v === 'light' || v === 'dark' ? v : 'system';
  } catch {
    return 'system';
  }
}

export function storeTheme(storage: Pick<Storage, 'setItem' | 'removeItem'>, theme: Theme): void {
  try {
    if (theme === 'system') storage.removeItem(THEME_KEY);
    else storage.setItem(THEME_KEY, theme);
  } catch {
    // Storage blocked: the theme still applies for this page load.
  }
}

export function applyTheme(
  theme: Theme,
  root: ThemeRoot,
  systemPrefersDark: boolean,
): 'light' | 'dark' {
  const resolved = theme === 'system' ? (systemPrefersDark ? 'dark' : 'light') : theme;
  root.classList.toggle('dark', resolved === 'dark');
  root.style.colorScheme = resolved;
  return resolved;
}

// Inlined in <head> so the theme is set before first paint. Keep dependency-free:
// it runs as a plain script, not as part of the bundle.
export const themeInitScript = `(function(){try{var t=localStorage.getItem('${THEME_KEY}');var d=t==='dark'||(t!=='light'&&matchMedia('(prefers-color-scheme: dark)').matches);var r=document.documentElement;r.classList.toggle('dark',d);r.style.colorScheme=d?'dark':'light'}catch(e){}})()`;
```

```tsx
import { createContext, useCallback, useContext, useEffect, useState, type ReactNode } from 'react';
import { applyTheme, readStoredTheme, storeTheme, type Theme } from '@/lib/theme';

interface ThemeContextValue {
  theme: Theme;
  setTheme: (theme: Theme) => void;
}

const ThemeContext = createContext<ThemeContextValue | null>(null);

const DARK_QUERY = '(prefers-color-scheme: dark)';

export function ThemeProvider({ children }: { children: ReactNode }) {
  // Lazy init so the first effect applies the stored theme, not a "system" flash.
  const [theme, setThemeState] = useState<Theme>(() =>
    typeof window === 'undefined' ? 'system' : readStoredTheme(window.localStorage),
  );

  useEffect(() => {
    const mq = window.matchMedia(DARK_QUERY);
    applyTheme(theme, document.documentElement, mq.matches);
    if (theme !== 'system') return;
    const onChange = () => applyTheme('system', document.documentElement, mq.matches);
    mq.addEventListener('change', onChange);
    return () => mq.removeEventListener('change', onChange);
  }, [theme]);

  const setTheme = useCallback((next: Theme) => {
    storeTheme(window.localStorage, next);
    setThemeState(next);
  }, []);

  return <ThemeContext.Provider value={{ theme, setTheme }}>{children}</ThemeContext.Provider>;
}

export function useTheme(): ThemeContextValue {
  const ctx = useContext(ThemeContext);
  if (!ctx) throw new Error('useTheme must be used inside <ThemeProvider>');
  return ctx;
}
```

```go
// Package adminapp serves the SPA shell of the new admin frontend (frontend/).
package adminapp

import (
	"bytes"
	"encoding/json"
	"regexp"
	"strings"
)

const (
	// AssetPrefix is the URL (and stuffbin) prefix the frontend build is served under.
	AssetPrefix = "/admin/app/"

	// ShellPath is the stuffbin path of the prerendered SPA shell.
	ShellPath = AssetPrefix + "_shell.html"
)

// reSafeRootPath matches a conservative URL path: it is interpolated into HTML
// attributes and a <script> block, so anything else is ignored.
var reSafeRootPath = regexp.MustCompile(`^/[A-Za-z0-9._~-]+(/[A-Za-z0-9._~-]+)*$`)

// RewriteShell prepares the built shell for serving. rootPath is the path
// component of app.root_url ("/" or "" when there is none). It prefixes asset
// URLs with rootPath and injects window._LM_ROOT as the first element of <head>,
// which the frontend uses for the router basepath and lazy chunk URLs.
func RewriteShell(shell []byte, rootPath string) []byte {
	prefix := strings.TrimRight(rootPath, "/")
	if prefix != "" && !reSafeRootPath.MatchString(prefix) {
		prefix = ""
	}

	out := shell
	if prefix != "" {
		out = bytes.ReplaceAll(out, []byte(AssetPrefix), []byte(prefix+AssetPrefix))
	}

	// json.Marshal escapes <, > and & so the value is safe inside <script>.
	root, _ := json.Marshal(prefix)
	script := []byte(`<script>window._LM_ROOT=` + string(root) + `;</script>`)

	i := bytes.Index(out, []byte("<head"))
	if i < 0 {
		return out
	}
	end := bytes.IndexByte(out[i:], '>')
	if end < 0 {
		return out
	}
	at := i + end + 1

	res := make([]byte, 0, len(out)+len(script))
	res = append(res, out[:at]...)
	res = append(res, script...)
	res = append(res, out[at:]...)
	return res
}
```
